Pharmacokinetic Covariates

Not applied to V/F — tacrolimus is ~75–80% RBC-bound and Størset 2014 fits no albumin exponent.

Note: Inhibitors reduce hepatic CL/F (Moderate ×0.65, Strong ×0.25). Bilirubin uses a continuous power-law: CL ∝ (1/Bil)^0.30 — no step discontinuity. HCT is handled by the standalone HCT Correction Tool; it is not a structural CL covariate in this whole-blood model.

💊 Starting Dose Guide (Population-Based, Pre-Bayesian)

Suggests a starting BID regimen from genotype, weight, and interacting drugs alone — for use before any trough level has been drawn. CYP3A5 expressers need a higher starting dose than non-expressers (CPIC); this pulls that from the same population model used for the MAP Bayesian forecast below, so weight, MPA, bilirubin, and CYP3A4 inhibitor status are already factored in. Once a level is logged, use the individualized forecast instead — this estimate never sees observed levels.
